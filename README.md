# 🔐 Password Strength Checker

A simple and efficient tool to check the strength of a password based on security rules like length, complexity, and character variety.

##  Features

- Checks password strength (Weak / Medium / Strong)
- Validates:
  - Minimum length
  - Uppercase & lowercase letters
  - Numbers
  - Special characters
- User-friendly output
- Lightweight and fast
